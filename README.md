## 👨‍💻 About Me

I'm a **Full Stack Developer** and **Backend & Platform Engineer** based in **Yogyakarta, Indonesia** with a strong focus on:

- 🏗️ Building scalable backend systems with **Node.js/TypeScript** and **Python**
- 🐘 Designing robust databases with **PostgreSQL** and **Prisma**
- ☁️ Deploying and managing cloud infrastructure with **Docker**
- 🔐 Platform security and system hardening

Currently building **MigunaniMotor** — an omnichannel spare parts platform, handling everything from API design to deployment.

> 🎯 **Open for remote opportunities abroad** — I'm eager to bring my skills to international teams and challenging projects.
